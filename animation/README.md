# Реалистичные анимации Life with Labr

Это сгенерированные видео с прозрачным фоном, не интерактивные 3D-модели.

Исходные кадры созданы встроенным ImageGen. Видео сгенерированы через ComfyUI на предоставленной пользователем GPU-машине: LTX-2.3 22B distilled FP8, 8 шагов, CFG 1, 768 × 512, 24 кадра/с. Первый и последний кадры закреплены одним исходным изображением для замыкания движения. Звук отсутствует.

- `source-puppy-v1.png` — исходный щенок.
- `labrador-loop-api.json` — API-схема генерации бега на месте, 97 кадров.
- `source-sitting-labradors-v1.png` — исходная пара взрослых собак.
- `sitting-labradors-loop-api.json` — API-схема спокойной сидящей пары, 121 кадр.
- `PROMPTS.md` — запросы для исходных изображений; запросы движения сохранены в узле 3 соответствующих API-схем.

В основе схем — [официальный пример LTX-2.3 FLF2V от ComfyUI](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/video_ltx2_3_flf2v.json). Для повторного запуска нужно загрузить исходный PNG в ComfyUI и при необходимости обновить его имя в узле `LoadImage`. Нужны checkpoint LTX-2.3 distilled FP8 и текстовый энкодер Gemma 3 12B FP4; секреты и адрес GPU-машины в схемы не включены.

При подготовке для сайта зелёная подложка удалена с сохранением альфа-канала, убраны её цветовые отражения, кадры обрезаны по внешним полям и уменьшены до 480 × 306. Повтор последнего кадра исключён. Итоговые WebM VP9 с прозрачностью и статичные WebP находятся в `dist/assets/`.

Браузер загружает ролики при появлении блока на экране. При сокращении анимаций в системных настройках, невозможности автозапуска или отсутствии поддержки формата остаётся статичное изображение. Вне экрана и в скрытой вкладке воспроизведение приостанавливается.
