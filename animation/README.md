# Реалистичные анимации Life with Labr

На сайте используются анимированные WebP с прозрачным фоном. Их исходники — сгенерированные видео, не интерактивные 3D-модели.

Исходные кадры созданы встроенным ImageGen. Видео сгенерированы через ComfyUI на предоставленной пользователем GPU-машине: LTX-2.3 22B distilled FP8, 8 шагов, CFG 1, 768 × 512, 24 кадра/с. Первый и последний кадры закреплены одним исходным изображением для замыкания движения. Звук отсутствует.

- `source-puppy-v1.png` — исходный щенок.
- `labrador-loop-api.json` — архивная схема генерации бега на месте, больше не используется на сайте.
- `source-puppy-ball-v1.png` — исходный щенок в игровом поклоне перед оранжевым мячом.
- `puppy-ball-api.json` — API-схема игры с мячом и переката на спину, 193 кадра.
- `source-sitting-labradors-v1.png` — исходная пара взрослых собак.
- `sitting-labradors-loop-api.json` — API-схема спокойной сидящей пары, 121 кадр.
- `PROMPTS.md` — запросы для исходных изображений; запросы движения сохранены в узле 3 соответствующих API-схем.

В основе схем — [официальный пример LTX-2.3 FLF2V от ComfyUI](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/video_ltx2_3_flf2v.json). Для повторного запуска нужно загрузить исходный PNG в ComfyUI и при необходимости обновить его имя в узле `LoadImage`. Нужны checkpoint LTX-2.3 distilled FP8 и текстовый энкодер Gemma 3 12B FP4; секреты и адрес GPU-машины в схемы не включены.

При подготовке для сайта зелёная подложка удалена с сохранением альфа-канала, убраны её цветовые отражения, кадры обрезаны по внешним полям и уменьшены до 480 × 306. Итоговые WebM VP9 с прозрачностью и статичные WebP находятся в `dist/assets/`.

`sitting-labradors-v2.webm` — новый 10-секундный цикл сидящей пары. Исходные 121 кадр проигрываются вперёд, затем кадры 119…1 назад. Пограничные кадры не дублируются: между последним и первым кадром — обычный соседний шаг движения. Это убирает перескок при повторном запуске ролика. Спокойные повороты головы сохраняют постоянную скорость воспроизведения при наведении.

WebM VP9 оставлены как промежуточные исходники. Для сайта они заменены на `puppy-ball-v2.webp` и `sitting-labradors-v3.webp`: воспроизведение VP9 само по себе не гарантирует поддержку его альфа-канала, что приводило к чёрному прямоугольнику на Mac. [Animated WebP поддерживает прозрачность в Safari](https://developers.google.com/speed/webp/faq).

Изображения загружаются лениво штатным `loading="lazy"`. `<picture>` выбирает неподвижный WebP при `prefers-reduced-motion: reduce`; отдельный JS-проигрыватель и разрешение автозапуска больше не требуются.

На главной — один щенок с одним мячом, `puppy-ball-v1.webm`, 480 × 320, около 595 КиБ. Он играет лапой, перекатывается на спину и возвращается в игровой поклон. Скорость постоянная; движение и мяч не проигрываются назад. Последние полсекунды спокойной позы смешаны с первыми полсекунды, затем начало временной шкалы перенесено за перекрытие. Обрезаны только прозрачные поля; лапы, хвост и мяч остаются внутри кадра. Постер извлечён из первого кадра готового цикла.

Повторный экспорт из исходного MP4 ComfyUI:

```sh
node animation/export-puppy-ball.mjs path/to/puppy-ball.mp4 path/to/ffmpeg
```
