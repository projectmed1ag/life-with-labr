# Life with Labr

Сайт питомника лабрадоров Евгении Скобликовой. Статический HTML, CSS и JavaScript без сборщика и внешних зависимостей. Все фотографии предоставлены заказчиком. Шрифты сохранены локально.

## Предпросмотр

Из корня проекта: `node preview.mjs`, затем `http://127.0.0.1:4173`.

## Содержание

- `dist/index.html` — главная страница и контакты.
- `dist/style.css` — адаптивная вёрстка и анимации, включая prefers-reduced-motion.
- `dist/app.js` — профили, достижения и родословные собак; меню, галерея и лайтбокс.
- `dist/assets/` — фотографии и локальные шрифты.
- `.openai/hosting.json` — идентификатор Sites и статическая директория.

Телефон и факты перенесены из предоставленных материалов. Информация о доступности щенков предлагается к уточнению напрямую у заводчика. Почта не добавлена: в двух исходных изображениях её написание отличается. Фото женщины не подписано как портрет Евгении, поскольку личность человека на фотографии не подтверждена.

Изображения взрослых собак извлечены из предоставленных снимков страниц; оригинальные фотографические водяные знаки сохранены. Полноразмерные оригиналы улучшат детализацию этих двух карточек.
