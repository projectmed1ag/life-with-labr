# Life with Labr

Сайт питомника лабрадоров Евгении Скобликовой. Статические страницы на HTML, CSS и JavaScript без внешних зависимостей. Все фотографии предоставлены заказчиком. Шрифты сохранены локально.

Сайт: https://lifewithlabr.ru/

Технический адрес Timeweb: https://projectmed1ag-life-with-labr-a619.twc1.net/

Для основного домена `lifewithlabr.ru` подготовлена [конфигурация Timeweb](deploy/timeweb.md): HTML/CSS/JS, ветка `main`, директория сборки `dist`, путь проекта — корень репозитория.

Репозиторий: https://github.com/projectmed1ag/life-with-labr

## Предпросмотр

Из корня проекта: `node build.mjs`, затем `node preview.mjs` и `http://127.0.0.1:4173`.

Контент редактируется в `src/pages/`, общая шапка, контакты и подвал — в `src/layout.html`. Команда `node build.mjs` создаёт пять страниц, переходы со старых адресов и sitemap в `dist/`. Стили и JavaScript редактируются непосредственно в `dist/`. Для проверки ссылок и структуры после сборки: `node check.mjs`. Порт предпросмотра можно задать переменной `PORT` (по умолчанию 4173).

## Содержание

- `dist/index.html` — главная страница с анонсами разделов.
- `dist/about/index.html` — о питомнике и заводчике, адрес `/about/`.
- `dist/dogs/index.html` — собаки, достижения и родословные, адрес `/dogs/`.
- `dist/puppies/index.html` — щенки и поддержка будущих владельцев, адрес `/puppies/`.
- `dist/moments/index.html` — фотоальбом с полноэкранным просмотром, адрес `/moments/`.
- `dist/style.css` — адаптивная вёрстка и анимации, включая prefers-reduced-motion.
- `dist/pages.css` — оформление отдельных страниц, анонсов и активных пунктов меню.
- `dist/app.js` — профили, достижения и родословные собак; меню, галерея и лайтбокс.
- `dist/living-puppies.*` — прозрачные видео-анимации под кнопками на главной и на странице питомника, с поддержкой сокращения движений и паузой вне экрана.
- `animation/` — исходные изображения, запросы и API-схемы ComfyUI для повторной генерации анимаций.
- `dist/assets/` — фотографии и локальные шрифты.
- Публикация — Timeweb App Platform из ветки `main`, директория `dist/`. GitHub Pages отключён, ветка `gh-pages` удалена; повторно включать этот хостинг без запроса владельца не нужно.

Все страницы открываются напрямую и после перезагрузки благодаря отдельным каталогам с `index.html`. Ссылки и адреса ресурсов начинаются от корня домена. Старые файлы `about.html`, `dogs.html`, `puppies.html` и `moments.html` переводят посетителя на новые адреса через `location.replace`, сохраняя параметры и якорь; без JavaScript работает meta refresh. Старые ссылки `/#about`, `/#dogs`, `/#puppies` и `/#moments` также переходят на соответствующие страницы. Контакты доступны внизу каждой страницы.

Телефон и факты перенесены из предоставленных материалов. Информация о доступности щенков предлагается к уточнению напрямую у заводчика. Почта не добавлена: в двух исходных изображениях её написание отличается. Фото женщины не подписано как портрет Евгении, поскольку личность человека на фотографии не подтверждена.

Изображения взрослых собак извлечены из предоставленных снимков страниц; оригинальные фотографические водяные знаки сохранены. Полноразмерные оригиналы улучшат детализацию этих двух карточек.
