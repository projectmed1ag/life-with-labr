# Размещение Life with Labr в Timeweb App Platform

Основной адрес: `https://lifewithlabr.ru/`.

Параметры готовой статической сборки:

- Репозиторий: `https://github.com/projectmed1ag/life-with-labr`
- Ветка: `main`
- Тип: Frontend → HTML/CSS/JS
- Директория сборки: `dist`
- Путь до директории проекта: пустой (корень репозитория)
- Node.js: 24 (на статическую сборку не влияет)
- Сборка по последнему коммиту: включена
- Команда сборки на платформе не требуется: готовые файлы включены в Git.
- Перед отправкой изменений: `node build.mjs`, затем `node check.mjs`.

Все страницы используют относительные пути. `canonical`, sitemap и robots.txt содержат основной домен. Сайт размещается только в Timeweb: GitHub Pages отключён по запросу владельца, ветка `gh-pages` удалена. Код остаётся в репозитории для автоматического деплоя Timeweb из `main`; публикацию GitHub Pages повторно не включать без отдельного запроса.

Домен добавляется в настройках приложения. Если домен и приложение находятся в разных аккаунтах Timeweb, домен добавляется как внешний; A-запись в аккаунте регистратора должна указывать на точный IP, показанный в настройках приложения. Существующие MX и TXT для почты сохраняются. Сертификат выпускается платформой после привязки домена.

Документация: [статические сайты](https://timeweb.cloud/docs/apps/deploying-frontend-apps/static-website), [привязка домена](https://timeweb.cloud/docs/apps/upravlenie-apps-v-paneli).
